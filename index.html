Cloudflare Worker Setup



OpenClaude sends requests to your Cloudflare Worker. Keep GEMINI_API_KEY in Cloudflare Worker Secrets. Never paste it into this website.













Locks your Worker so only people with the token can use your Gemini quota. Saved in this browser only. It is left out of exported files.








If this model is overloaded, the app automatically tries gemini-3.6-flash, then gemini-flash-lite-latest.













Connect apps through Composio. Your Composio API key stays in Cloudflare.
